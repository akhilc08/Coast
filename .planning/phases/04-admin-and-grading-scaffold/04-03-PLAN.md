    3. Filter tabs:
       - Links: All / Paid / Signing / Complete — each links to ?status={value}
       - Same active/inactive styling as listings page

    4. Table:
       - Columns: Order # (truncated UUID, first 8 chars), Vehicle (make model year from joined listings), Buyer (email from joined profiles), Amount (format price_cents / 100 as USD), Status (human-readable badge), Date (formatted created_at)
       - Status badge mapping:
         - pending_payment = "Pending" (zinc)
         - paid = "Paid" (blue)
         - documents_sent = "Signing" (yellow/amber)
         - documents_signed = "Signed" (green)

       - Empty state: "No orders found"

    5. Style: same as listings table — bg-zinc-900, border-zinc-800, text-sm body.
