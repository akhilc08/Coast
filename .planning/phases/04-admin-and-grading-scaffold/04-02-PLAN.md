    Replace the placeholder dashboard page with the full analytics dashboard. This is a Server Component.

    1. Data fetching (all via createAdminClient()):
       - Revenue: query orders.select('price_cents') where status IN ('paid', 'documents_sent', 'documents_signed', 'complete'), sum price_cents client-side
       - Listings: count all listings (count: 'exact', head: true), count active listings (.eq('status', 'active'))
       - Orders: count all orders (count: 'exact', head: true)
       - Users: query profiles.select('role'), count total, count where role='wholesaler'
       - Recent orders: query orders.select('id, price_cents, status, created_at, listings(make, model, year), profiles!buyer_id(email)').order('created_at', { ascending: false }).limit(5)

    2. Render:

         - Listings: show total with "({activeCount} active)" subtitle
         - Orders: show total count

       - Recent Orders section below cards:
         - h2 "Recent Orders"
